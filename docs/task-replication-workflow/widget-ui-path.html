Widget & UI Path

WBP_Inventory  — tablet UI casting to GameState

Breaking Change — Update Required
Every widget that previously did Cast to BP_PS_Gameplay to read task lists or progress must be updated to Cast to BP_GS_Gameplay instead. Failure to do so will result in the tablet showing stale or empty task data for clients other than the host.

Node-by-Node Migration: WBP_Inventory

The following diff shows which Blueprint nodes to remove and which to add in the Event Construct and Refresh Task List functions of WBP_Inventory.

WBP_Inventory → Event Construct / Refresh Task List
// --- Obtain reference to task data source --- - Get Owning Player Pawn - → Get Controller - → Get Player State - → Cast To BP_PS_Gameplay - → Get ActiveTasksList (PlayerState variable) + Get Game State (no cast needed for base ref) + → Cast To BP_GS_Gameplay + → Get ActiveTasksList (GameState variable — replicated) // --- Build task row widgets --- For Each Loop (ActiveTasksList) Create Widget (WBP_TaskRow) Pass: TaskItem reference - Pass: Progress from BP_PS_Gameplay.TaskProgressMap[TaskID] + Pass: Progress from BP_GS_Gameplay.TaskProgressMap[TaskID] - Pass: Goal from BP_PS_Gameplay.TaskGoalMap[TaskID] + Pass: Goal from BP_GS_Gameplay.TaskGoalMap[TaskID] Add to Scroll Box // --- Mark globally completed tasks --- - (was not handled — only local player's tasks shown as complete) + Get BP_GS_Gameplay.GloballyCompletedTaskIDs + For Each row: if Contains(GloballyCompletedTaskIDs, row.TaskID) + → Set row visual state = Completed (green check, full bar)

Live Refresh via RepNotify

For the tablet to update while it is open (i.e., another player completes a task without the local player reopening the tablet), implement the following in BP_GS_Gameplay:

BP_GS_Gameplay — OnRep_CompletedTaskIDs
// This fires on every client whenever GloballyCompletedTaskIDs changes. + Event OnRep_CompletedTaskIDs + → Get Player Controller (0) + → Get HUD → Cast to BP_HUD_Gameplay + → Call RefreshTaskUI // Inside BP_HUD_Gameplay → RefreshTaskUI: + If WBP_Inventory is visible: + Call WBP_Inventory → RefreshTaskList + Also trigger completion notification / HUD popup
Alternative — Poll on Tick
If RepNotify-driven refresh feels complex, a simpler approach is to poll every 0.25s using a Set Timer by Function Name in WBP_Inventory → Event Construct that calls RefreshTaskList. This works but is less efficient. RepNotify is the recommended Unreal approach.

Task Row Completion Visual State

Inside WBP_TaskRow, use the following logic to decide which visual state to display: 

// WBP_TaskRow → Event Construct / RefreshState

GS = Cast to BP_GS_Gameplay (Get Game State)

Progress = GS.TaskProgressMap[TaskID]    // default 0 if not found
Goal     = GS.TaskGoalMap[TaskID]        // set on BeginPlay from task actor defaults
IsGloballyDone = GS.GloballyCompletedTaskIDs.Contains(TaskID)

if IsGloballyDone:
    Progress Bar Fill = 1.0 (100%)
    Tint = Green  (#22c55e)
    Show checkmark icon
else:
    Progress Bar Fill = Progress / Goal
    Tint = default (#3b82f6)
    Hide checkmark icon
