RTT Note
RTT (round-trip time) is the network latency between client and server. For a local LAN game this is near zero; for online play expect 30–120ms. Because we use Reliable RPCs and Unreal's reliable replication channel, the task completion will always eventually reach the server — it is never silently lost.
